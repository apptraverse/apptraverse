## Пауза и работа с окном во время загрузки

Исправленная сборка опубликована под ID `lifecycle-pause-demo` (R0–R3) на прежнем клиенте Æther. Локальный тест на реальных Win32-контролах проверил доступность обоих списков, проверки каталога и обеих кнопок обновления при активной загрузке. Проверка каталога завершается независимо от загрузки. Прогрессбар сохранил 65 536 Б из 399 285 Б на паузе. После закрытия и открытия состояние осталось на паузе. Нажатие «Продолжить» возобновило загрузку с 65 536 Б и активировало русский после получения пакета. Отдельный тест выбрал R1 при незаконченной загрузке русского R0. Версия переключилась, а уже принятые байты русского R0 остались в кеше. Оба режима обновления и переход между R1 и R3 прошли локально.

На GCE Windows получила R3 для `lifecycle-pause-demo` и R1 для `lifecycle-demo-alt`. Через Æther повторно проверены прогресс, доступность контролов, проверка каталога, пауза через рестарт и переключение локализации после явного продолжения. Результаты в `artifacts/update-lifecycle/acceptance-pause-local.log` и `artifacts/update-lifecycle/acceptance-pause-cloud.log`.

Классический UpdateLab прошёл smoke на Win32 и GTK/X11. Нативный state test прошёл на Windows и Linux.
