# UpdateLab LZMA1 — 2026-11-23

Windows x64 (MSVC v143 Debug) и Ubuntu x64 в WSL (Clang Debug) собраны инкрементально. Для доставки Linux использовались копии ELF после strip и отдельные символы. Локальная команда сервисного клиента `update_lab_provider publish` выпустила R0–R3 с 24 компонентами в общем каталоге Windows/Linux. Профили и поставки предыдущего формата сохранены.

| Проверка | Исполненный сценарий и результат |
| --- | --- |
| Native state test, обе ОС | PASS. Полные native-состояния и дельты, изменения слоёв и удалений, S1/origin, пустой и однобайтный входы, 8192 повторяющихся байта, отклонение обрезанного завершения LZMA1 |
| Процессная матрица | 44/44. Чистая установка каждой Windows R и Linux R3, объявление последней версии, точная оценка байтов, дельты в обе стороны, kill/resume, атомарная смена языка, USER Windows→Linux→Windows, сохранение LOCAL, ObjId и S1 override, смена и откат исполняемого файла |
| Независимое чтение поставки | Python/liblzma декодировал все 28 файлов в images через FILTER_LZMA1 до маркера окончания. Размеры совпали. Распакованные PE и ELF побайтово совпали с соседними исполняемыми файлами |
| UI | Нативные Win32 и GTK/X11 под Xvfb прошли native-smoke. Оба процесса записали native-smoke.ok |
| Реальный Æther | 4/4 Windows. Остановка процесса в середине загрузки, продолжение с подтверждённой позиции, активация E1/S1, сбой E2 с возвратом состояния. Отдельный Linux E0 получил R0→R1 и полный русский пакет у Windows-поставщика через Æther |
| Миграция предыдущего кодека | Новый launcher с новым E0 и отдельной установкой открыл копию прежнего native-профиля R3. База, русский, немецкий и E1 были получены из нового каталога. Сравнение подтвердило идентичность ObjId, заметки, S1, инвентаря, языка и байтов LOCAL. Конвертер прежнего portable USER дал побайтово те же распакованные данные (2321 Б), затем приложение успешно импортировало новый файл |

На пути R0/E0→R3/E1 для установленного неактивного русского три базовые и две языковые дельты суммарно заняли 751 Б. Включая сжатый EXE, план потребовал 1 344 030 Б на Windows и 1 748 773 Б на Linux. Полный образ доступен для отдельной чистой установки каждой версии. [Сравнение на одинаковых входах](../update_lab_compression.md#файлы-поставки-lzma1).
